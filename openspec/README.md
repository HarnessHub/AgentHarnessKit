# OpenSpec Workspace

This directory holds the planning and source-of-truth artifacts for AgentHarnessKit.

- `specs/` stores stable, accepted repository behavior and conventions
- `changes/` stores proposed or active changes that are still being implemented or validated

OpenSpec is responsible for planning truth. It does not replace `.codex/pm/`, which remains the local execution-state layer for issues, tasks, issue-state, and delivery tracking.
